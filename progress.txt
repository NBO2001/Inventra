## Codebase Patterns
- Run `isort`, `black`, `flake8`, and `pytest` from `/workspace/inventra-collector` so the service-local config and imports resolve correctly.
- The collector flow keeps transport concerns at the edges: the Kafka key carries `key_access`, while the Kafka value is retry metadata JSON with `attempt` and `next_try`.

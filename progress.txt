## Codebase Patterns
- Run `isort`, `black`, `flake8`, and `pytest` from the `inventra-collector/` service directory so the local config and imports resolve correctly.
- The collector flow keeps transport concerns at the edges: the Kafka key carries `key_access`, while the Kafka value is retry metadata JSON with `attempt` and `next_try`.
- Keep collector workflows injectable for tests by passing publishers, clocks, rate limiters, and client factories into application services.
- Host processes must use Kafka at `127.0.0.1:29092`; the `kafka:9092` address is only resolvable from other containers on the Compose network.
- Treat `Config.load(dotenv_path)` as authoritative for tests and local overrides by letting the dotenv file overwrite existing environment variables.
- The collector must use an explicit Kafka consumer group; with a fresh group, `KAFKA_AUTO_OFFSET_RESET=earliest` is what makes existing topic backlog get consumed.
